# Security policy

## Supported versions

Security fixes go into the latest stable release of Station and Scout. Older
releases don't receive backports. The `latest` images follow `main`; use a
versioned release image for a stable deployment.

## Report a vulnerability

Use GitHub's private [Report a vulnerability](https://github.com/thesteau/3to1go/security/advisories/new)
form. Please keep vulnerability details out of public issues and pull requests.
If the form isn't available, open an issue asking the maintainer to enable it,
without describing the vulnerability.

Include the Station or Scout version, how you're running it, steps to reproduce
the problem, and what an attacker could do. A small example helps. Remove passwords,
Station tokens, Scout keys, signing keys, private hostnames, and backup data
from logs and attachments. Keep exploit details private while the report is reviewed.

There's no guaranteed response time. Where possible, the maintainer will work
with you on a fix and agree on when to publish the details.
