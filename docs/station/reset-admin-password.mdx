---
title: "Reset the admin password"
description: "Regain access to Station if you're locked out."
---

`INITIAL_ADMIN_PASSWORD` is only used when Station starts with no user accounts. Changing it later does **not** reset an existing account. `POSTGRES_PASSWORD` is the database password, not the sign-in password.

If you can still sign in, use **Admin → Change My Password**. Another admin can also reset your password in **Users & Access**, which signs you out everywhere and makes you choose a new one.

If you're locked out, reset the password directly in PostgreSQL:

<Steps>
  <Step title="Go to the Station folder">
    SSH into the Docker host and change into the folder with Station's `docker-compose.yml`:

    ```sh
    cd 3to1go-central
    ```
  </Step>
  <Step title="Reset the password to admin">
    ```sh
    docker compose exec postgres psql -U three_to_one_go -d three_to_one_go -c "CREATE EXTENSION IF NOT EXISTS pgcrypto; UPDATE app_users SET password_hash = crypt('admin', gen_salt('bf', 10)), must_change_password = true WHERE username = 'admin';"
    ```

    If you changed `POSTGRES_USER` or `POSTGRES_DB` in `.env`, use those values in place of `three_to_one_go`.

    Existing sessions stay signed in.
  </Step>
  <Step title="Sign in and choose a new password">
    Open Station and sign in with username `admin` and password `admin`. Station requires you to set a new password right away.
  </Step>
</Steps>
