Station **receives and keeps** backups. Run it on one always-on host, such as a home server, NAS, or VPS. Every Scout uploads to it.

## What Station does

- **Receives uploads** from Scouts in chunks, and verifies each one before storing it.
- **Stores snapshots** as encrypted archive files under `scout_id/scout_instance_id/job_name` in its backup folder.
- **Applies retention**, keeping the most recent snapshots per job and instance.
- **Mints and revokes Station tokens**, so only Scouts you've authorized can upload.
- **Checks integrity** on a schedule, if enabled.
- **Lists snapshot history and lets you download or delete snapshots** in its web UI. Your browser decrypts downloads with the Scout key you provide.
- **Sends restore requests to a Scout**, including another device, for its operator to accept. Station doesn't decrypt the snapshot or send the Scout key.
- **Sends notifications** to ntfy and runs your own scripts when uploads arrive.

Scout encrypts each archive before uploading it. Station receives the encrypted archive and metadata such as job names, timestamps, sizes, and checksums. It doesn't receive the Scout key or decrypt the files inside the archive.

## What it runs

| Component | Purpose |
|---|---|
| `ghcr.io/thesteau/3to1go-station` | The Station app and web UI, on port `6555` |
| `postgres:17-alpine` | Stores snapshot metadata, users, settings, Scout registrations, and Station token records |

The example Compose file runs both. See [Install Station](/station/install).

## Folders it uses

| Inside the container | Holds |
|---|---|
| `/backups` | Stored snapshots. Point this at the disk, NAS, or synced folder you want. |
| `/staging` | Uploads in progress |
| `/config` | Station's signing key (`issuer.key`) and trusted certificates |
| `/hook-scripts` | Scripts you upload for [hooks](/station/hooks) |

<Warning>
  Back up Station's `config` folder. `issuer.key` signs Station tokens. If it's lost, every existing token stops working and each Scout needs a new one.
</Warning>
