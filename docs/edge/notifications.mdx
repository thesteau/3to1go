---
title: "Edge notifications"
description: "Get an ntfy message when Edge successfully uploads a job to Central."
---

Edge can post a message to an [ntfy](https://ntfy.sh) topic after a job uploads **successfully**. Publishing is optional and best-effort: a failed notification never blocks an upload.

<Note>
  Central has its own, separate notification settings that fire when Central receives an upload. See [Central notifications](/central/notifications). Configure whichever side you prefer, or both.
</Note>

## Set up

<Steps>
  <Step title="Open the dialog">
    In Edge, click **Configure ntfy**.
  </Step>
  <Step title="Enter your server and topic">
    - **ntfy Server URL**: for example `https://ntfy.sh` or your own server.
    - **Topic**: for example `backups`.
  </Step>
  <Step title="Test and save">
    Click **Test** to send a sample message, then **Save**.
  </Step>
</Steps>

If your ntfy server uses a private CA, add it under [Trusted certificates](/shared/trusted-certificates).

## Message template

The default message is:

```text
Edge uploaded {{ edge_id }}/{{ edge_instance_id }} job {{ job_name }} to Central as {{ stored_as }}.
```

Write your own in **Message Template**. **Defaults** restores the default.

| Placeholder | Value |
|---|---|
| `{{ edge_id }}` | This Edge's ID |
| `{{ edge_instance_id }}` | This Edge installation's instance ID |
| `{{ job_name }}` | Name of the backup job |
| `{{ stored_as }}` | Filename as stored on Central |

Messages are sent with the header `X-Relay-Event: upload-finished`.
