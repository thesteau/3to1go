Send backup notifications to HTTP services. URLs and headers are secret: saved values are never shown again.

Use HTTPS for this UI when entering secrets. Setup and service guides

Each destination is a separate action with its own URL and templates. For different before and after actions, save a PRE destination and a separate POST destination. HTTP delivery runs in the background; use a PRE script when processing must wait for an action to finish.

Plain text sends this message. JSON event includes it in the message field. Custom JSON can insert it with {{ message }}. Reset changes the draft; click Save to apply it.

Enter valid JSON. Put variables inside string values, for example {"message": "{{ message }}"}. Values are escaped automatically.
